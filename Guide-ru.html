MegaProg — приложение для macOS, которое выполняет утверждённый план разработки через подключённый сервис выполнения. Оно хранит требования и прогресс в проекте, выполняет задачи по очереди и запускает проверки из плана.

Пример: две функции калькулятора

Снимки показывают учебный план и состояние после двух настоящих запусков задач. Текст плана для показа переведён; путь проекта заменён условным, личные данные и показатели расхода убраны. Скриншоты на немецком и английском находятся в соответствующих инструкциях.

Подготовьте JSON-план с целью, разрешёнными файлами, критериями приёмки и командами проверок. Проверьте его перед открытием и утверждением в MegaProg. Сведения о проекте перед передачей внешнему сервису нужно просмотреть.

Что умеет MegaProg

  • Хранит требования и очередь задач отдельно от истории чата.
  • Выполняет утверждённые задачи по очереди в общем бюджете запусков.
  • Запускает проверки из плана и сохраняет результаты.
  • Сохраняет прогресс для остановки и продолжения работы.
  • Показывает прогресс, доступные данные о расходе и причину остановки.

MegaProg не гарантирует, что план учёл все требования, код всегда правильный или программа экономит лимит по сравнению с прямым выполнением. Проверяйте план, команды, изменения кода и результаты.

Первый запуск на macOS

Пакет Preview предназначен для Mac с Apple Silicon. Приложение подписано ad hoc; у него нет подписи Apple Developer ID и нотариализации. macOS может предупредить о неизвестном разработчике. Открывайте приложение только после проверки исходников и контрольной суммы выпуска. Если вы решили продолжить, после первой блокировки macOS покажет действие Open Anyway для этого приложения в «Настройки системы» → «Конфиденциальность и безопасность». Не отключайте Gatekeeper целиком. Инструкция Apple.

  1. Скачайте MegaProg-4.5.1-macos-arm64.zip из раздела Releases.
  2. Распакуйте архив и переместите MegaProg.app в «Программы».
  3. Откройте MegaProg. Нажмите «Попробовать на примере», чтобы создать учебный проект без Терминала, либо выберите существующий Git-проект. На шаге «Подключение» нажмите «Проверить подключение».
  4. Подключите поддерживаемый сервис выполнения и войдите по подписке. MegaProg удаляет переменные окружения API-ключа и не переключается на отдельно оплачиваемый API.
  5. Подготовьте сведения о проекте, необходимые для плана. Перед передачей файлов внешнему сервису проверьте их содержимое.
  6. Укажите цель, критерии приёмки, файлы, проверки и бюджет запусков. Проверьте план и сохраните его как JSON без Markdown.
  7. Откройте JSON в MegaProg. Просмотрите функции, разрешённые файлы и каждую команду проверки. Само открытие ничего не запускает.
  8. Нажмите «Утвердить и выполнить» или «Сохранить без запуска». Для остановки между задачами выберите «Одна задача и пауза». Чтобы продолжить, снова откройте MegaProg и выберите сохранённый план.

Команды проверок — исполняемые программы. Они запускаются на Mac от имени вашей учётной записи. Утверждайте планы и команды только из источников, которым доверяете. Сделайте резервную копию Git и проверьте изменения до использования или публикации.

Кнопка «Попробовать на примере» создаёт новую папку с Git и открывает план из двух функций с бюджетом в два хода. Существующие папки не перезаписываются. Выполнение запускается только после вашего утверждения. Те же план и исходники примера доступны в репозитории.

Что понадобится

  • macOS на Apple Silicon для пакета Preview. Другие версии macOS пока не проверялись отдельно.
  • Отдельно установленный компонент подключения с действующим входом по подписке. Настройка описана в технической документации режима утверждённого плана. Техническая настройка.
  • Git-проект. Планы и данные запуска хранятся в .ai-dev/ внутри проекта.

Исходный код и тесты также работают с Python 3.9 и новее. Для сборки приложения нужен Python 3.12 с PySide6 и инструменты из requirements-build.txt.

Сборка из исходников

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-build.txt
python packaging/build.py --output /tmp/megaprog-release

Для сборки нужен чистый Git checkout. Приложение, исходники, контрольные суммы и ZIP появятся в выбранной папке. Подробнее: сборка и выпуск.

Данные и ограничения

MegaProg работает локально. Планы, состояние, журналы проверок и ссылки на сессии выполнения находятся в .ai-dev/ выбранного проекта. При необходимости просмотрите или удалите их. В репозитории нет ваших данных входа. Выполнение использует подключённый внешний сервис, ваш аккаунт и рабочее пространство. Handoff может содержать локальные пути и сведения о задачах — проверьте его перед прикреплением к другому чату.

Информация для участников — CONTRIBUTING.md, безопасность — SECURITY.md, лицензия — GPL-3.0-only. MegaProg — независимый проект сообщества.

Новый мастер

Проект → Подключение → План → Выполнение → Результат. После просмотра нажмите «Утвердить и выполнить» или «Сохранить без запуска». Сохранённый план выбирается явно на первом шаге. Доступны системная, светлая и тёмная темы и полный русский, немецкий и английский интерфейс. Пакет при необходимости передаётся выбранному сервису планирования вручную. При запуске из исходников установите интерфейс: python -m pip install ".[gui]".
