MegaProg

Запускает согласованные задачи разработки через Codex и сохраняет требования, проверки и прогресс проекта.

Предварительная версия · 4.5.1 macOS · Apple Silicon
Скачать для macOS Исходный код Python · PySide6 Руководство ↗

Перед запускомОтдельно установите Codex CLI и войдите через аккаунт ChatGPT с доступом к Codex; нужен Git-проект. Приложение не нотарифицировано Apple.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Первый запуск на macOS» руководства.

1. Скачать ZIP из GitHub Releases и распаковать
2. Перенести MegaProg.app в папку «Программы»
Если macOS предупреждает: Системные настройки → Конфиденциальность и безопасность → Всё равно открыть
3. Выбрать «Попробовать на примере» или открыть Git-проект, затем «Проверить подключение»
4. Войти в Codex с аккаунтом ChatGPT
5. Открыть план как JSON, проверить его и запустить кнопкой «Утвердить и выполнить»

Ваши данные

MegaProg работает локально. Планы, состояние и протоколы проверок лежат в .ai-dev/ вашего проекта. Задачи обрабатывает Codex с аккаунтом ChatGPT, в который вы вошли; в репозитории нет данных для входа.

Данные локально в .ai-dev/Codex с аккаунтом ChatGPT
