What's inside

Installation, features, data flow and checks.

Installation

The steps from “Get started on macOS” in the guide.

1. Download the ZIP from GitHub Releases and unzip it
2. Move MegaProg.app to the Applications folder
If macOS warns: System Settings → Privacy & Security → Open Anyway
3. Choose “Try the tutorial” or open a Git project, then “Check connection”
4. Sign in to Codex with a ChatGPT account
5. Open the plan as JSON, review it and run it with “Approve and run”

Your data

MegaProg runs locally. Plans, status and check logs are stored under .ai-dev/ in your project. Codex processes the tasks with the ChatGPT account you are signed in to; the repository contains no sign-in data.
