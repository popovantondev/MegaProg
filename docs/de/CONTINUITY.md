# Arbeit fortsetzen

Die MegaProg-Entwicklung folgt der [Roadmap](PRODUCT_ROADMAP.md); Entscheidungen stehen in [DECISIONS.md](DECISIONS.md). Informationen zur Planausführung finden Sie in [APPROVED_PLAN_MODE.md](APPROVED_PLAN_MODE.md).

Der öffentliche Quellcode enthält keine privaten Pfade, Projektspeicher oder Aufgabenprotokolle. Exportieren Sie für einen neuen Chat einen aktuellen Handoff und hängen Sie ihn manuell an: ChatGPT kann Dateien auf dem Mac nicht selbst lesen. Ein Handoff ist eine Momentaufnahme, weder ein Backup noch die Erlaubnis, Befehle auszuführen.
