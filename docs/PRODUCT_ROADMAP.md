# MegaProg product roadmap

## Preview goal

Help a new macOS user review a plan prepared in ChatGPT, approve it in
MegaProg, run Codex tasks sequentially, inspect checks, and resume saved work.

## Current release scope

- Approved-plan mode with persistent feature requirements, queue, dependencies,
  model-turn budget, verification evidence, and pause/resume.
- A macOS desktop flow in Russian, German, and English.
- A portable Apple Silicon Preview package with a bundled Python/Qt runtime.
- A two-feature example, three-language guides, offline CI, and a clean source
  release with GPL-3.0-only and checksums.

## Later

- Apple Developer ID signing and notarization.
- Verify a supported minimum macOS version on a second machine.
- Windows release validation and localization review.
- Quantitative comparison of complete Work/Architect/Codex cost against direct
  Codex use before making savings claims.
- Parallel execution or additional routing only with a measured product need.

## Rules for status

Mark a feature complete only when source and checks support it. Record the
tested commit, environment, results, and any limits in release notes. A handoff
is a saved context snapshot, not proof that code is correct.

## Desktop redesign 4.5.0

Implemented and offline-verified: centred four-node/check icon, five-step Qt wizard, system/light/dark themes, RU/DE/EN, reviewed-byte import, explicit saved-plan selection, asynchronous CLI, truthful stop/proof/usage states, portable context export. Exact packaged-app acceptance is recorded beside each candidate.

## Follow-up 4.5.1

Offline-verified: specific project-folder diagnostics and retained selected paths; invalid project selection clears the old reviewed plan. Icon nodes are paired diagonally by color and size. Demo checks avoid generated bytecode. Package evidence is recorded with the candidate.
