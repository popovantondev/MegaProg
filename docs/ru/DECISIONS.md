# Продуктовые решения

- Аудитория: люди, которые впервые работают с помощниками для программирования.
- Первая поддерживаемая цель: Mac с Apple Silicon. Другие платформы не объявляются проверенными.
- Пользователь обсуждает и утверждает план в ChatGPT, затем открывает JSON в MegaProg.
- Первый публичный выпуск — предварительная версия с подписью ad hoc, без подписи Apple Developer ID и нотариализации; системная защита macOS остаётся включённой.
- Лицензия: GPL-3.0-only.
- Интерфейс и документы выпуска доступны на русском, немецком и английском.
- Не обещать гарантированную экономию лимитов или отсутствие ошибок.
- Не публиковать учётные данные, частную память проектов, личные handoff или пути этого компьютера.
