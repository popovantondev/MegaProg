# Сборка Preview для macOS

Сборщик предназначен для Apple Silicon. Закреплённая версия PyInstaller включает в приложение интерфейс, Python и Qt; отдельный ZIP содержит разрешённый список исходников, тесты, тексты лицензий runtime-компонентов, GPL-3.0-only и манифест контрольных сумм. `SHA256SUMS.txt` содержит хэши обоих архивов. Сборка подписывает готовый пакет ad hoc и проверяет подпись; она не получает подпись Apple Developer ID, не нотариализирует, не устанавливает и не загружает приложение.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-build.txt
git status --short
python packaging/build.py --output /tmp/megaprog-release
```

Папка результатов должна быть пустой. Сборка требует чистой копии Git и Apple Silicon Mac. Приложение и архив исходников должны происходить из одного commit. До выпуска проверьте хэши, просмотрите состав архива, запустите приложение в чистой учётной записи и завершите ограниченную проверку из [VALIDATION.md](VALIDATION.md).

Приложите к выпуску `MegaProg-4.5.1-third-party-source.zip` с проверенными копиями исходников Qt и PySide6. Их состав указан в [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md); ссылки на сайт Qt не заменяют этот архив.
Файл хэшей сборщика относится к двум его архивам. В итоговой папке выпуска создайте `SHA256SUMS.txt` для всех трёх архивов.

Preview имеет подпись ad hoc, но не имеет подписи Apple Developer ID и не нотариализирован. Пользователю можно показать действие **Open Anyway** отдельно для этого приложения, если он доверяет сборке. Не советуйте отключать Gatekeeper полностью.

Не включайте личные handoff, память проектов, журналы запусков, учётные данные, личные данные проектов, старые архивы и конфигурацию компьютера. До публикации человек должен проверить конкретные файлы и текст страницы выпуска.
