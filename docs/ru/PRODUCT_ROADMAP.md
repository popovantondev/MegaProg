# Дорожная карта MegaProg

## Цель Preview

Помочь новому пользователю проверить план, подготовленный в ChatGPT, утвердить его в MegaProg, последовательно выполнить задачи Codex, посмотреть проверки и продолжить сохранённую работу.

## Объём Preview

- Утверждённый план сохраняет требования к функциям, очередь, зависимости, лимит модельных ходов и результаты проверок.
- Интерфейс macOS доступен на русском, немецком и английском.
- Пакет для Apple Silicon включает Python и Qt.
- В комплект входят пример из двух функций, инструкции на трёх языках, автоматические офлайн-проверки, исходный код под GPL-3.0-only и контрольные суммы.

## Позже

- Подпись Apple Developer ID и нотариализация (в Preview используется только ad-hoc-подпись).
- Проверка минимальной версии macOS на другом компьютере.
- Проверка выпуска для Windows и перевод интерфейса.
- Сравнение общей стоимости полного процесса с прямой работой в Codex перед любыми заявлениями об экономии.
- Параллельные исполнители и дополнительный выбор моделей — только при измеренной необходимости.

Функция считается готовой только со ссылками на исходники и результаты проверок. Перед выпуском записывайте commit, среду, результаты и ограничения.

## Дополнение 4.5.1

Офлайн-проверено: конкретные ошибки выбора проекта с сохранением выбранного пути; неверный выбор сбрасывает прежний просмотренный план. Узлы значка попарно совпадают по диагоналям цветом и размером. Проверки примера не создают байткод. Проверки точного пакета записаны рядом с кандидатом.
