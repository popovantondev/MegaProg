# MegaProg 4.5.1 Preview — проверки

## Финальный кандидат, 27 сентября 2026 года

- Итоговый офлайн-набор: 556 тестов, 553 пройдены, 3 пропущены. Публичный снимок исходников и приложение из пакета прошли release-check, строгую проверку подписи macOS, проверку CLI и запуск окна с пустым `HOME` в текущей учётной записи.
- Точное приложение из пакета прошло реальный учебный запуск: обе функции калькулятора получили `VERIFIED`, обе задачи — `COMPLETED` с первой попытки. Сохранённый план показывает 2/2 хода исполнителя. После паузы первая задача не выполнялась повторно.
- Сохранённый расход этого запуска: 115 471 входной токен, включая 104 448 кэшированных; 789 выходных, включая 82 токена рассуждения. Сравнения с прямой работой в Codex нет.
- Шесть скриншотов плана и результата на трёх языках находятся в `docs/screenshots/`. Для показа использовано сохранённое завершённое состояние с переведённым учебным текстом и условным путём. Личные пути и показатели расхода на снимки не перенесены.
- Исходники подготовлены к публикации; эти проверки выполнены локально. Отдельная учётная запись macOS, второй Mac и GitHub Actions пока не проверены.

Данные ниже относятся к более ранним контрольным точкам 4.5.1 и сохранены как история.

## Подтверждено на macOS 15.7.4 / Apple Silicon

- Офлайн-набор: 547 тестов, 544 пройдены, 3 пропущены; 243,315 секунды.
- 31 проверка мастера: изменение файла во время подтверждения, импорт
  просмотренных данных, остановка и закрытие, выбор плана, смена языка,
  кнопки при минимальной ширине и увеличении шрифта на 25%.
- Две задачи через окно и отдельные процессы CLI с тестовым исполнителем:
  закрытие и повторное открытие между задачами, без повторения первой,
  проверки обеих функций и экспорт контекста прошли. Реальных запросов к модели не было.
- База 4.5.0: 84 демонстрационных снимка: RU/DE/EN × две темы × 1120×780/860×620 ×
  пять страниц и состояния блокировки/остановки. Просмотрены характерные варианты.
- Загружаются русские и немецкие переводы стандартных диалогов Qt.
- Геометрия плитки сохранена; измерение 4.5.0: MegaProg — 81,25% поля; Finder и Safari — 80,47%.
  Разница примерно 0,97%, в пределах согласованных 5%.
- Окно переведено на Qt. Ядро и формат approved-plan v1 сохранены.

Проверка: `PYTHONDONTWRITEBYTECODE=1 QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v`.
Снимки: `QT_QPA_PLATFORM=offscreen python packaging/preview_gui.py --output /tmp/megaprog-preview`.

## Дополнение 4.5.1

- После последних изменений текста и размещения повторно пройдены 39 проверок интерфейса за 96,946 секунды.
- Разные сообщения для исходников из ZIP, вложенной или отсутствующей папки, отсутствующего Git и ошибок доступа. Выбранный путь сохраняется; неверный выбор сбрасывает прежний план. Содержимое выбранной папки не меняется.
- У значка противоположные узлы попарно совпадают: небольшие мятные и более крупные бирюзовые.
- Сообщение об ошибке просмотрено в светлой теме на русском при 860×620. Матрица из 84 снимков выше относится к 4.5.0 и не выдаётся за новое измерение.
- Подготовлен учебный план двух функций с бюджетом двух ходов. Подготовка и локальная проверка подключения не запускают задачи модели.
- На исправленном кандидате 4.5.1 (`89c2eb3`) отдельно выполнен реальный прогон Codex: обе учебные функции завершены ровно за два хода исполнителя. После первой задачи приложение остановлено, закрыто и открыто вновь; продолжение того же плана не повторило первую задачу. Проверки обеих функций прошли. Codex сообщил 115 371 входной токен (106 496 из кеша) и 594 выходных; длительность — 1 559,497 секунды. Это данные одного прогона, а не сравнение с прямой работой в Codex.

упакованной версии на macOS записываются в отдельный отчёт рядом с кандидатом.
Они не следуют автоматически из модульных тестов или реального прогона
на исправленном кандидате.
