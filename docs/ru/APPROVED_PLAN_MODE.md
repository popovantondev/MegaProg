# Выполнение утверждённого плана

MegaProg получает из чата JSON-план, который пользователь проверил и утвердил. Чат не видит файлы на компьютере, пока пользователь не прикрепит их или не вставит сведения в переписку. MegaProg проверяет структуру плана до запуска.

## Формат

План использует `schema_version: 1`, уникальный `plan_id`, `objective`, `budget.max_model_turns`, `features` и `tasks`. У функции есть критерии приёмки и команды проверки. У задачи есть функция, инструкции, зависимости, разрешённые относительные пути, команды проверки и, при необходимости, файлы контекста. Поддержаны Luna и Sol; по умолчанию Luna medium. Неизвестные зависимости и циклы отклоняются.

## Порядок работы

1. Откройте файл и изучите функции, пути, бюджет и каждую команду проверки. Чтение файла не запускает команд.
2. Нажмите «Утвердить и сохранить».
3. Запустите весь план или выполните одну задачу, чтобы остановиться между шагами.
4. После перезапуска откройте тот же Git-проект и продолжите сохранённый план.
5. Просмотрите результаты проверок, отчёты и изменения в Git.

Проверки — настоящие команды программ. Они выполняются от имени вошедшего в систему пользователя. Утверждайте команды только если понимаете и доверяете их назначению.

## Сохранение и ограничения

Неизменяемый JSON хранится в `.ai-dev/approved-plans/PLAN_ID/plan.json`; состояние, журналы и подтверждения результатов находятся рядом. Функция считается проверенной после успешной проверки её задач и повторных проверок ранее завершённых функций. Сохраняются лимит модельных ходов, существующий лимит попыток, песочница и подтверждения. Режим последовательный; автоматической установки и публикации нет.
