# Продолжение работы

Разработка MegaProg ведётся по дорожной карте [PRODUCT_ROADMAP.md](PRODUCT_ROADMAP.md); принятые решения перечислены в [DECISIONS.md](DECISIONS.md). Сведения о выполнении плана находятся в [APPROVED_PLAN_MODE.md](APPROVED_PLAN_MODE.md).

Публичный исходный код не содержит личных путей, внутренней памяти проектов или журналов задач. Для нового чата экспортируйте свежий handoff и вручную прикрепите его: обычный ChatGPT не может сам читать файлы на Mac. Handoff — снимок состояния на момент экспорта, а не резервная копия или разрешение на запуск команд.
