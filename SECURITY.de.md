# Sicherheitsrichtlinie

Melden Sie vermutete Schwachstellen zuerst privat an die Maintainer, bevor Sie ein öffentliches Issue eröffnen. Nennen Sie Version, kurze Beschreibung, Reproduktionsschritte und Auswirkungen. Senden Sie keine Zugriffstoken, Passwörter oder Codex-Sitzungsdateien.

MegaProg führt planbasierte Prüfkommandos auf Ihrem Mac aus und gewährt Codex im Rahmen seiner Berechtigungen Zugriff auf das ausgewählte Projekt. Prüfen Sie Pläne, Befehle und Änderungen. Geben Sie unbekannte Befehle nicht frei. Die Preview ist nicht von Apple signiert oder notariiert.
