MegaProg

Führt freigegebene Entwicklungsaufgaben über Codex aus und speichert Anforderungen, Prüfungen und Fortschritt.

Vorabversion · 4.5.1-preview.1 macOS · Apple Silicon
Herunterladen für macOS Quellcode Python · PySide6 Anleitung ↗

Vor dem StartCodex CLI separat installieren und mit einem ChatGPT-Konto mit Codex-Zugang anmelden; Git-Projekt nötig. Keine Apple-Notarisierung.

Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „Erste Schritte auf macOS“ in der Anleitung.

1. ZIP aus GitHub Releases laden und entpacken
2. MegaProg.app in den Ordner „Programme“ verschieben
Warnt macOS: Systemeinstellungen → Datenschutz & Sicherheit → Trotzdem öffnen
3. „Mit Beispiel ausprobieren“ wählen oder ein Git-Projekt öffnen, dann „Verbindung prüfen“
4. Bei Codex mit einem ChatGPT-Konto anmelden
5. Plan als JSON öffnen, prüfen und mit „Freigeben und starten“ ausführen

Ihre Daten

MegaProg läuft lokal. Pläne, Status und Prüfprotokolle liegen unter .ai-dev/ in Ihrem Projekt. Die Aufgaben verarbeitet Codex mit dem ChatGPT-Konto, bei dem Sie angemeldet sind; das Repository enthält keine Anmeldedaten.
